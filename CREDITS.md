# Credits

**The Horizon Protocol** - a game by Tanmay, built in Godot with Claude.

- 3D models: made in Blender from code (`tools/blender_assets.py`)
- Textures: generated from code (`tools/gen_textures.py`)
- Sound effects and music: synthesised from code (`tools/gen_audio.py`)
- Voices: generated with the [Piper](https://github.com/rhasspy/piper) neural text-to-speech engine,
  LibriTTS voice model (dataset licensed CC BY 4.0) - see `tools/gen_voice.py`
